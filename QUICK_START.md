# Quick Start - Adventure Table

Get your game running in 5 minutes!

## Step 1: Deploy to Vercel (2 minutes)

1. Go to **https://vercel.com/new**
2. Click **"Import Git Repository"**
3. Paste: `https://github.com/jmsbkck34-maker/adventure-table`
4. Click **"Import"**
5. Vercel will auto-configure everything
6. Click **"Deploy"**
7. Wait ~2 minutes for build to complete
8. You'll get a link like: `https://adventure-table-xyz.vercel.app`

✅ Your game is now live!

---

## Step 2: Share with Players (1 minute)

Send your players this link:
```
https://adventure-table-xyz.vercel.app
```

They can:
- Open in web browser (no download needed)
- Use Discord in another window for voice chat
- Start playing immediately

---

## Step 3: Run Your First Session (2 minutes)

### As the DM:
1. **Generate a dungeon:**
   - Click "Tools" → "Map Generator"
   - Click "🏰 Generate Dungeon"
   - See your map appear

2. **Create NPCs & monsters:**
   - Click "Tools" → "Campaign Tools"
   - Generate NPCs for your world
   - Generate an encounter for combat

3. **Find monsters & spells:**
   - Click "Reference" → "D&D Beyond"
   - Search for monsters
   - View spell descriptions

### For Players:
1. Open the shared Vercel link
2. Upload their character portrait as a token
3. Place their token on the map
4. Roll dice and fight!

## Troubleshooting

**"Build failed on Vercel"**
- Wait 5 minutes and refresh
- Check that you have 5GB free space
- Try deploying again

**"Connection timeout"**
- Make sure both players are on same network
- Or use Discord for video chat instead of VTT voice

**"Maps aren't syncing"**
- Refresh the page
- Make sure you're both on the latest version
- Try a different browser (Chrome recommended)

**"I want local development"**
```bash
git clone https://github.com/jmsbkck34-maker/adventure-table.git
cd adventure-table
yarn install
yarn start
# Opens http://localhost:3000
```
